# ESP32 OCPP Charging Station\n\nA complete OCPP 1.6-J client implementation for ESP32 microcontrollers, designed for electric vehicle charging stations using Clean Architecture principles.\n\n## Features\n\n- **Complete OCPP 1.6-J Implementation**\n  - Core Profile (required)\n  - Firmware Management Profile\n  - Local Auth List Management Profile\n  - Reservation Profile\n  - Smart Charging Profile\n  - Remote Trigger Profile\n\n- **Clean Architecture**\n  - Domain-driven design\n  - SOLID principles\n  - Dependency injection\n  - Interface-based abstractions\n\n- **ESP32 Optimized**\n  - Dual-core task distribution\n  - Memory-efficient JSON handling\n  - Hardware abstraction layer\n  - Over-the-air updates ready\n\n## Quick Start\n\n### Prerequisites\n- PlatformIO IDE or PlatformIO Core\n- ESP32 development board\n- OCPP-compatible central system\n\n### Build and Upload\n\n```bash\n# Build the project\npio run\n\n# Upload to ESP32\npio run -t upload\n\n# Monitor serial output\npio device monitor\n```\n\n### First Boot\n\n1. ESP32 will start WiFi configuration portal\n2. Connect to \"ESP32-OCPP-Setup\" network\n3. Configure WiFi credentials and OCPP settings\n4. Device will connect to central system\n\n## Configuration\n\nEdit `data/config.json` for OCPP settings:\n\n```json\n{\n  \"centralSystemUrl\": \"ws://your-central-system:8080/steve/websocket/CentralSystemService\",\n  \"chargePointId\": \"ESP32_CP_001\",\n  \"heartbeatInterval\": 300,\n  \"numberOfConnectors\": 1\n}\n```\n\n## Hardware Setup\n\nSee `include/config.h` for GPIO pin assignments:\n- GPIO2: Charging relay control\n- GPIO34: Current sensor (ADC)\n- GPIO16/17: RFID reader (UART)\n- GPIO18: Status LED\n- GPIO19: Connector detection\n- GPIO21: Emergency stop\n\n## Development\n\n### Architecture\n\nProject follows Clean Architecture with four layers:\n\n```\nsrc/\n├── domain/          # Business logic and entities\n├── application/     # Use cases and application services\n├── infrastructure/  # External concerns (OCPP, WiFi, hardware)\n└── presentation/    # User interfaces (web, serial, LEDs)\n```\n\n### Adding New Features\n\n1. Define domain interfaces in `src/domain/interfaces/`\n2. Implement infrastructure in `src/infrastructure/`\n3. Wire dependencies in `src/main.cpp`\n\n### Testing\n\nTest with OCPP central systems:\n- [SteVe](https://github.com/RWTH-i5-IDSG/steve)\n- [OCPP-J Server Simulator](https://github.com/extrawest/Websocket_OCPP_1.6_Server_Simulator)\n\n## License\n\nMIT License - See LICENSE file for details\n\n## Contributing\n\nContributions welcome!
